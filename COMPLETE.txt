🎯 DATA STRUCTURES IMPLEMENTED:

1. MinHeap (backend/src/data-structures/MinHeap.js)
   • Binary min-heap for expiry priority
   • O(log n) insert, O(log n) extract, O(1) peek
   • Used for FEFO recommendations

2. HashMap (backend/src/data-structures/HashMap.js)
   • Hash table with collision handling (chaining)
   • O(1) insert, search, delete (average case)
   • Auto-resizing when load factor > 0.75

3. AlertQueue (backend/src/data-structures/AlertQueue.js)
   • Circular array implementation
   • O(1) enqueue, O(1) dequeue
   • FIFO alert management

4. HistoryLinkedList (backend/src/data-structures/HistoryLinkedList.js)
   • Doubly linked list with head & tail
   • O(1) insert front/back, O(n) search
   • Bidirectional traversal
